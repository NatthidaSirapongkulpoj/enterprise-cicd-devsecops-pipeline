# Interview Notes

## Why Docker?

Docker provides consistent environments across development, testing, and production.

---

## Why Terraform?

Terraform enables Infrastructure as Code (IaC), making infrastructure version-controlled, repeatable, and automated.

---

## What is CI/CD?

Continuous Integration automatically validates every code change.

Continuous Deployment automates software delivery to cloud infrastructure.

---

## Why GitHub Actions?

GitHub Actions provides native CI/CD integration with GitHub repositories and supports automated testing, security scanning, and deployment.

---

## Why Amazon ECR?

Amazon ECR is a managed container registry that securely stores Docker images before deployment.

---

## Why EC2?

Amazon EC2 provides scalable virtual machines for hosting containerized applications.

---

## Why Unit Testing?

Unit tests ensure application functionality remains stable after every code change.
