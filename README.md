# Enterprise CI/CD DevSecOps Pipeline

> Enterprise CI/CD pipeline using GitHub Actions, Docker, Terraform and DevSecOps security scanning.

---

## 📌 Overview

This project demonstrates how to design and implement a production-style CI/CD pipeline using GitHub Actions.

The pipeline automates:

- Code validation
- Docker image build
- Infrastructure validation
- Security scanning
- Automated testing
- Release automation

---

## 🛠 Technology Stack

- GitHub Actions
- Docker
- Terraform
- Python
- Trivy
- Checkov
- Gitleaks
